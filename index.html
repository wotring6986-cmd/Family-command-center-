Install Family Command Center

Put the app on your Home Screen for one-tap access

📲 Install this app

Family Command Center is an installable web app. Your family can add it to iPhone, iPad, Android phones and tablets without an app-store download.

Checking this device…

Android

🤖
One-tap install when availableChrome and many Android browsers can show an Install App prompt automatically.
Open in ChromeUse the public Family Command Center link in Chrome.
Tap Install AppUse the purple button above, or Chrome menu ⋮ → Install app / Add to Home screen.
Open from your Home ScreenIt launches like a regular app in its own window.

iPhone & iPad

🍎
Add to Home ScreenApple does not allow a website button to silently install a web app, so Safari needs one quick Add to Home Screen action.
Open in SafariIf you opened the link from Gmail, Facebook or another in-app browser, use Share → Open in Safari.
Tap Safari’s Share buttonIt looks like a square with an arrow pointing up.
Choose Add to Home ScreenThen tap Add. Family Command Center will appear with its app icon.
Open the Home Screen appThis also enables iPhone web-push support when you allow notifications.
Already installed? Open Family Command Center from your Home Screen for the best experience.
